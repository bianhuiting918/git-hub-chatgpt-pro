# NylC A1 q_attack recovery design

## Purpose

Recover a constrained Step1 attack bracket after job 62012919 completed numerically but failed to reach its short-distance targets. The recovery remains scouting only and cannot establish a TS, committor, PMF, barrier, or mechanism.

## Frozen scientific contract

- SCNet only; Amber18 DFTB3/3OB-3-1 on eight CPU MPI ranks per attempt.
- A1 microstate: Thr267 N-alpha-H3+/O-gamma-minus, Asp306=ASH, Asp308=ASP-.
- Unified Step1 QM region: Tyr146, Lys189, Asn219, Thr267, Asp306, Asp308 and complete PA66-L2.
- 146 explicit QM atoms, six link H, charge 0, singlet, 510 electrons.
- Step1 has no QM water.
- Keep the O2-C12-OG1 angle flat bottom at 95-115 degrees.
- Preserve job 62012919 and all prior outputs; every recovery attempt uses a new immutable snapshot and output directory.

## Recovery array

Start all replicas from the same q03 restart generated by job 62012919, whose achieved OG1-C12 distance is 2.846836 A. Run the common targets 2.65, 2.45, 2.25, 2.05, 1.85 and 1.65 A sequentially. Use 150 steepest-descent steps per window and keep the existing 1.0 kcal mol-1 A-2 restraint on non-QM solute heavy atoms.

The only varied parameter is the distance-restraint force constant:

- replica 0: 50 kcal mol-1 A-2;
- replica 1: 100 kcal mol-1 A-2;
- replica 2: 200 kcal mol-1 A-2.

For all replicas set r1=target-0.25 A, r2=target-0.025 A, r3=target+0.025 A and r4=4.50 A. This keeps expected geometries inside the quadratic branch rather than the capped linear tail.

## Gates

Each window must finish with no SCC, vlimit, bond-overflow, NaN, FATAL, SANDER BOMB, segmentation, or forrtl finding. Record achieved distance, attack angle, C12-O2, C12-N3, all three N-alpha-H distances, minimization energy, RMS and GMAX.

A replica is an attack-bracket seed only if its endpoint has OG1-C12 <=1.90 A, angle 95-115 degrees, C12-O2 <=1.70 A and C12-N3 <=1.80 A. These broad bond-length checks only reject broken geometry; the audit must separately state whether C12-O2 lengthens and/or C12-N3 changes relative to the common start.

If several replicas pass, select the weakest-force replica that reaches the gate without hard numerical findings. Do not compare raw restrained minimized energies as a PMF or activation barrier. Do not begin Step2 until Step1 has a defensible product/intermediate basin.
